Aquest és el meu [github](https://github.com/2627arturbartomeu/OperacioNordTec).

Avui hem après a com utilitzar github des de zero i a més em après a com pujar un arxiu.
1. Primer hem fet un `git init` per inicialitzar el projecte.
2. Desprès hem fet un `git add README.md` per preparar els canvis.
3. Desprès amb `git commit -m "Inici"` guardat l'estat actual del *README.md*.
4. Desprès amb `git branch -m Main` he canviat el nom de la branca perquè és deia master en comptes de main.
5. Desprès utilitzem `git remote add origin url` per vinvular el repositori remot.
6. Fianlment fem un `git push` per pujar a github els canvis que hem fet.
---
| Comanda | Que fa? |
| --------------- | --------------- |
| `git init` | Crea repositori buit |
| `git add` | Preparar els canvis |
| `git remote` | Llistar repositoris remots |
